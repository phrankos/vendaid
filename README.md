# VendAid - Patient Prescription Management System

## Initial Setup
1. Do `composer install` to install backend dependencies.
2. Do `php artisan key:generate` to a new encryption key.
3. Do `npm install` to install frontend dependencies.
4. Do `php artisan migrate:fresh --seed` to migrate tables and initial seeding
5. Create .env from template. Edit database info.
---
## Run Web App
1. Do `composer run dev`
---

## Misc Information
1. Frontend Vue files are in the `./resources/` folder
